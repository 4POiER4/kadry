# Контроль присутствия (гибкий график)

Две страницы:

| Кто | Адрес | Что делает |
|-----|-------|-----------|
| **Сотрудник кадров** | `/hr` (вход по логину) | утром загружает выгрузку из проходной; приложение считает присутствие, подсвечивает строки, отдаёт Excel |
| **Обычный сотрудник** | `/` (без входа) | вводит фамилию или табельный номер и смотрит, во сколько пришёл и **во сколько можно уйти** |

Загруженный кадровиком файл остаётся в памяти приложения (и в резервной копии на
диске) — сотрудники весь день видят по нему свои данные, пока кадровик не загрузит
новый или не нажмёт «Убрать для сотрудников».

## Подсветка (страница кадров)

| Цвет | Условие |
|------|---------|
| 🟢 зелёный | присутствие ≥ нормы **и** приход не позже 09:00 |
| 🔵 синий | пришёл, выхода ещё нет, отчёт за сегодня («на работе») |
| 🔴 красный | недоработка **или** приход позже 09:00 (или неполные/некорректные отметки) |
| 🟡 жёлтый | нет отметок за день (отсутствие / отпуск / больничный) |

## Нормы (гибкий график)

Окно прихода: **08:00–09:00**. Уход — по факту прихода (пример: пришёл в 8:45 → уйти в 17:45).

| День | Норма присутствия (вход→выход, до обеда) | Обед | Зачётная норма |
|------|:--:|:--:|:--:|
| Понедельник–четверг | 9:00 | 0:45 | 8:15 |
| Пятница | 8:15 | 0:45 | 7:30 |

«Уйти не раньше» = приход (но не раньше 08:00) + норма присутствия. Приход раньше
08:00 рабочий день не сокращает; приход позже 09:00 считается от факта и помечается.

Все значения настраиваются через переменные окружения (см. `.env.example`).

## Запуск в Docker

```bash
cp .env.example .env      # поменяйте HR_PASSWORD и SECRET_KEY
docker compose up -d --build
```

- Сотрудники: <http://localhost:8163/>
- Кадры: <http://localhost:8163/hr> (логин/пароль из `.env`, по умолчанию `kadry` / `kadry`)

Порт хоста меняется переменной `HOST_PORT`. Остановить: `docker compose down`.

## Рабочий процесс

**Кадровик (утром):**
1. Открыть `/hr`, войти.
2. Перетащить файл выгрузки (`.xlsx`, `.xls`, `.csv`).
3. День недели определяется автоматически; при необходимости выбрать вручную и нажать «Обработать».
4. Файл сразу становится доступен сотрудникам. Вверху страницы — плашка «Доступно
   сотрудникам…» и кнопка «Убрать для сотрудников».
5. При желании — «Скачать Excel с подсветкой».

**Сотрудник (в течение дня):**
1. Открыть `/`.
2. Ввести фамилию (можно часть) или табельный номер — минимум 3 символа.
3. Увидеть время прихода и «Уйти не раньше».

## Хранение загруженного файла

Разобранный отчёт хранится в памяти процесса и дублируется в
`DATA_DIR/latest.json` (по умолчанию `/app/data`, том `kadry_data`), поэтому
переживает перезапуск контейнера. Полностью очищается кнопкой «Убрать для
сотрудников» или `POST /api/clear`.

## Формат входного файла

Стандартная выгрузка отчёта «Время прихода, ухода, присутствия» за **один день**:
строки шапки, затем строка заголовков (`Таб. №`, `Сотрудник`, `…[Вход]`, `…[Выход]`).
Столбцы ищутся по названиям; если заголовок не найден — берутся позиции A–F с
предупреждением в интерфейсе.

## Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `HOST_PORT` | `8163` | порт на хосте |
| `HR_USERNAME` / `HR_PASSWORD` | `kadry` / `kadry` | вход для кадров |
| `SECRET_KEY` | случайный | подпись cookie-сессии |
| `SESSION_HOURS` | `12` | срок жизни сессии |
| `TZ` | `Europe/Minsk` | часовой пояс (метки времени в отчёте) |
| `DATA_DIR` | `/app/data` | папка резервной копии загруженного файла |
| `LUNCH_MINUTES` | `45` | обед, минут |
| `ARRIVAL_WINDOW_START` / `ARRIVAL_WINDOW_END` | `08:00` / `09:00` | окно прихода |
| `REQUIRED_PRESENCE_MON_THU` | `9:00` | норма присутствия Пн–Чт |
| `REQUIRED_PRESENCE_FRI` | `8:15` | норма присутствия Пт |

## Структура

```
app/
  main.py          FastAPI: страницы, вход, публичное API сотрудников
  config.py        настройки из окружения
  parser.py        чтение xlsx/xls/csv, поиск заголовков и дня недели
  calc.py          расчёт присутствия, статуса и времени «уйти не раньше»
  store.py         последняя загрузка: память + DATA_DIR/latest.json
  excel_export.py  формирование итогового xlsx с подсветкой
  static/
    index.html / app.js        страница кадров
    employee.html / employee.js страница сотрудника
    login.html, style.css
```
